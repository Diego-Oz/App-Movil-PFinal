# 🎂 App-Movil-PFinal

App móvil Android de uso comercial para realizar pedidos de **repostería** a través de un carrito 
de compras. Incluye panel de administrador con autenticación y gestión completa de productos.

> Proyecto final académico — ITLA

---

## ✨ Funcionalidades

### Cliente
- 🛍 **Catálogo de productos** — visualización del menú de repostería disponible
- 🛒 **Carrito de compras** — agregar, eliminar y gestionar productos antes de confirmar el pedido
- 📦 **Realizar pedidos** — flujo completo de pedido desde el catálogo

### Administrador
- 🔐 **Login** — acceso protegido al panel de administración
- ✏️ **CRUD de productos** — crear, leer, actualizar y eliminar productos del catálogo
